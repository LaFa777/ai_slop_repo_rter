# online-fix-json.py

Скрапер для https://online-fix.me/ — собирает новые релизы и обновления с кооперативом (fa-check), выводит JSON.

## Запуск

Скрипт запускается только из корня репозитория (нужны папки `utils/` и `states/` рядом):

```bash
cd repo_rter
uv run online-fix-json.py
```

## Поведение

- **Первый запуск** — baseline: запоминает все URL в `states/online-fix.json`, ничего не выводит.
- **Последующие запуски** — выводит JSON только с новыми URL (которых не было в предыдущих запусках).
- **Нет новых статей** — stdout пуст (ничего не печатается).

## Поля в JSON

| Поле | Описание |
|------|----------|
| `title` | Название игры |
| `url` | Ссылка на страницу игры на online-fix.me |
| `edit_text` | Текст обновления (для обновлений) |
| `edit_is_nbsp` | `true` — новый релиз, `false` — обновление |
| `has_coop` | Есть кооператив |
| `has_coop_times` | Кооператив отключён |
| `game_info` | Описание игры со страницы |
| `store_url` | Прямая ссылка на страницу игры в Steam (или `"no-steam"`) |

## Устройство

- `utils/watermark.py` — класс `Watermark` для дедупликации; хранит `seen_ids` в JSON-файлах внутри `states/`.
- `states/` — служебная директория с watermark-файлами, добавлена в `.gitignore`.

### Фазы работы

1. Загрузка главной страницы через Crawl4AI (Chromium headless)
2. Парсинг HTML через BeautifulSoup — извлечение статей
3. Фильтрация по кооперативу (fa-check)
4. Категоризация — новые релизы vs обновления
5. Дедупликация через Watermark
6. Обогащение — загрузка полной страницы каждой новой статьи, извлечение `game_info` и `store_url`
   - `store_url` раскрывается через Crawl4AI: клик по ссылке `/ext/...` в браузере, переход на интерстициал, парсинг Steam URL из HTML
